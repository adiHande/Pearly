# Pearly

Pearly is a cute pixel-style memory matching game built with HTML, CSS, and JavaScript.

## Features

- Easy, Medium, Hard, and Expert difficulty levels
- Relaxed, Stopwatch, and Countdown game modes
- Randomized flower card pools
- Best score tracking with localStorage
- Sound effects for buttons, menus, toggles, card flips, matches, wins, losses, and transitions
- Custom Pearly mascot
- Responsive game interface
- Multiple game screens including Home, Game, Results, and Exit

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Play

1. Choose a difficulty level.
2. Choose a timer mode.
3. Click **Start Game**.
4. Flip two cards at a time and match all pairs.
5. Try to finish with fewer moves and a faster time.

## Difficulty Levels

- Easy — 6 pairs
- Medium — 10 pairs
- Hard — 14 pairs
- Expert — 20 pairs
